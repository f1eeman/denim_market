# Nîmes — магазин джинсовой одежды

Одиннадцать страниц плюс 404, у всех есть содержимое. Три свёрстаны по макету
Figma — главная, каталог и карточка товара; остальные собраны из измеренных токенов
там, где макета нет вовсе.
Astro, статическая сборка, Yarn.

Проект **собирается, проходит линт, типы и браузерные тесты** сразу после
`yarn install`.

## Страницы

По макету:

| Адрес      | Что на ней                                                      |
| ---------- | --------------------------------------------------------------- |
| `/`        | промо, «Bestsellers», новость, «Shop by category»               |
| `/catalog` | полоса коллекции с крошками, фильтр по цене, сетка, догрузка    |
| `/product` | галерея на пять кадров, выбор размера и цвета, корзина, «также» |

Без макета, из тех же токенов:

| Адрес                         | Что на ней                                   | В поиске |
| ----------------------------- | -------------------------------------------- | -------- |
| `/shop`                       | индекс четырёх категорий                     | да       |
| `/shop/overalls`              | три позиции Overalls из макета               | да       |
| `/shop/jeans`, `/shop/shirts` | кадр категории, крой, посадка, что в наличии | да       |
| `/delivery`                   | доставка, отслеживание, возврат, обмен, брак | да       |
| `/service`                    | размеры, уход за денимом, ремонт, связь      | да       |
| `/news`                       | статья новости целиком                       | да       |
| `/sitemap`                    | карта сайта для человека                     | да       |
| `404`                         | «не найдено» с четырьмя выходами             | нет      |

Текст этих страниц написан для магазина: условия доставки, размерная сетка и уход —
собственные условия Nîmes, а не заявления о мире.

Каталог отдаёт все 45 карточек в разметке; фильтр и «Load more» переставляют
`hidden`. Корзина живёт в `localStorage`, поиск в шапке уводит запрос в каталог.

## Движение

Заказано владельцем: три вступительных плана на CSS (промо, полоса каталога, плашка
товара), диагональное вытирание карточек по прокрутке, диптих новости, один
автономный цикл — клевок стрелки промо. Плюс такт у всех переключений, которые раньше
были рывком.

Инвариант: **никакой отказ не оставляет содержимое невидимым.** Под
`prefers-reduced-motion: reduce`, при упавшем бандле и без JS страница просто
собрана. Это не обещание, а два спека в `tests/motion.spec.ts`.

## Что внутри

| Слой       | Что именно                                                                                                                                                    |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Тулинг     | ESLint 10 с обходами, Stylelint, Prettier, husky + lint-staged, Playwright, Astro                                                                             |
| Модули     | `gsap.ts`, `reveal.ts`, `scenes.ts`, `parallax.ts`, `menu.ts`, `cart.ts`, `catalog.ts`, `product.ts`, `header-search.ts`                                      |
| Компоненты | `header`, `footer`, `button`, `hatch`, `section-head`, `product-grid`, `product-card`, `category-card`, `breadcrumbs`, `page-band`, `notice` и секции страниц |
| Данные     | `src/data/shop.ts`, `src/data/catalog.ts`, `src/data/grid.ts`, `src/data/pages.ts`                                                                            |
| Стили      | `reset.css`, измеренные токены, контейнер и вертикальный ритм                                                                                                 |
| Тесты      | 103 браузерных: шапка и поиск, меню, каталог, галерея и корзина, живость всех ссылок и 404, страховки сцен                                                    |

Шрифты — Work Sans (переменный, 400–800) и Anton 400, оба локально в
`src/assets/fonts/`. Картинки — `src/img/`, экспорты узлов макета; оптимизирует их
`astro:assets` на сборке.

Чего внутри нет намеренно: сцен со скролл-триггерами, вкладок, каруселей и лент.

## Команды

```
yarn dev            # дев-сервер на 4321
yarn build          # astro check && astro build
yarn preview        # просмотр сборки
yarn lint           # ESLint
yarn lint:styles    # Stylelint
yarn format         # Prettier
yarn test:browser   # Playwright: собирает и поднимает просмотр на 4331
```

**Только Yarn.** `npm install` при наличии `yarn.lock` перепишет его под себя и
сломает установку у коллег на других платформах.

## Что осталось заменить перед прод-выкладкой

Заглушек-страниц в проекте нет, но домена и настоящих данных нет тоже, поэтому
осталось заменить:

| Где                        | Что заменить                                   |
| -------------------------- | ---------------------------------------------- |
| `astro.config.mjs`         | `site` — сейчас `https://example.invalid`      |
| `public/robots.txt`        | адрес карты сайта                              |
| `src/components/seo.astro` | поля `ORGANIZATION`: телефон, почта, домен     |
| `public/favicon.svg`       | знак магазина                                  |
| `public/og-image.png`      | превью 1200×630 — файла нет, его надо положить |
| `src/data/catalog.ts`      | 37 придуманных позиций из 45                   |
| `src/data/shop.ts`         | `SOCIALS` ведут на главные страницы сетей      |

Все ссылки шапки и подвала ведут на живые страницы — это проверяет
`tests/pages.spec.ts`. `Woman`, `Man` и `New` ведут в `/shop`: это не категории, а
отдельных выдач под них макет не даёт.
